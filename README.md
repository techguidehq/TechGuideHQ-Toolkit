# TechGuideHQ-Toolkit

An automated workflow and infrastructure toolkit for content creation, server setup, and media processing under the Tech Guide HQ brand.

## Repository Structure
- automation/
  - watermark_images.py: Automated image and thumbnail watermarking tool.
  - format_shorts.py: Short-form video formatting and text helper.
  - web_scraper.py: Automated web scraper and data gathering script.
- server/
  - setup_server.sh: Shell script for quick remote server configuration.
- requirements.txt: Python package dependencies.
